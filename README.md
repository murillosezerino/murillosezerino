# 👋 Hi, I'm Murillo Sezerino

**Software Engineer · Full Stack | Python · Django · TypeScript · React · GraphQL · SQL · PostgreSQL · REST APIs · Docker · CI/CD**

I build the parts of a product that handle money and data: payments, billing and reporting. Python, Django, GraphQL, SQL and React are my everyday tools.

Before software I spent ten years in finance, credit and logistics (Loggi, Stone, PagBank), so I understand the business behind the code.
